# Consumer Product Preference Analysis

## Project Overview
This project analyzes supermarket sales data to understand consumer purchasing patterns, product preferences, and sales performance using Python data analysis and visualization libraries.

## Objectives
- Analyze sales statistics using NumPy.
- Identify popular product lines using Pandas.
- Clean and preprocess the dataset.
- Analyze sales trends and correlations between numerical variables.
- Visualize results using bar plots, scatter plots, pie charts, and heatmaps.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Dataset
The dataset contains supermarket transaction details, including:
- Product line
- Unit price and quantity
- Sales and gross income
- Customer type and gender
- City and branch
- Payment method
- Date and customer rating

## Project Workflow
1. Data loading and initial exploration
2. Data cleaning and preprocessing
3. NumPy-based sales statistics
4. Pandas-based product preference analysis
5. Sales trend and correlation analysis
6. Data visualization
7. Conclusions and insights

## Visualizations
The project includes:
- Bar plots for product-line sales and quantity
- Heatmap for city-wise product sales
- Scatter plot for unit price versus sales
- Pie chart showing each product line's share of total sales
- Line plot showing daily sales trends

## How to Run
1. Download or clone this repository.
2. Open the `.ipynb` notebook in Jupyter Notebook or Google Colab.
3. Upload the supermarket sales CSV dataset when prompted.
4. Run all cells in order to reproduce the analysis and visualizations.

## Conclusion
This project demonstrates how Python-based data analysis can help identify sales patterns, compare product performance, and understand consumer purchasing behavior.
